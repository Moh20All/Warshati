# Receipt

The paper container for the app's thermal templates: `paper` 80 or 58, black on white, no theme. Print classes: `p-shop`, `p-title`, `p-big`, `p-row`, `p-head`, `p-rule`, `p-rule-solid`, `p-total`, `p-small`, `p-box`, `p-logo`, `p-end`.

- Replaces Courier New with IBM Plex Sans (+ Plex Sans Arabic, Plex Mono for numbers) and the black "R" circle with the black Trace mark. The lines printed, and their order, stay as in each template.

**Keep the app's structure.** This restyles the existing component; it does not add, remove or rename props, fields, buttons or behaviour.
