# Toast

Restyles the app's toasts: bottom-right, 4 seconds, success · error · warning · info, with a close ×. Card background with a coloured icon instead of a full coloured fill, so the text stays readable.

**Provide** `tone`, children (the existing message).

**Keep the app's structure.** This restyles the existing component; it does not add, remove or rename props, fields, buttons or behaviour.
