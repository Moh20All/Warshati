# SegmentedSwitch

Style for the app's existing two/three-way switches: device category (Phone · Laptop · Console), POS Payment Method (Cash · Credit (Full) · Split), Existing/New customer, Feedback type.

**Provide** `options` (`{value, label, icon?}`), `value`, `block`.

- If the app shows one of these as buttons or a select today, it may stay that way; this is only the look.

**Keep the app's structure.** This restyles the existing component; it does not add, remove or rename props, fields, buttons or behaviour.
