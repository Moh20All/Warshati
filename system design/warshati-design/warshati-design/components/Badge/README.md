# Badge

Restyles `components/ui/Badge.jsx`: `default` · `primary` · `success` · `warning` · `danger` · `info`, each a soft tint with dark text (the app used 15% tints; these are fixed tokens so both themes pass contrast). For statuses use `StatusBadge`.

**Keep the app's structure.** This restyles the existing component; it does not add, remove or rename props, fields, buttons or behaviour.
