# StatCard

The figure cards of Dashboard (4), Daily Close (6) and Monthly Summary (5). Label, value, sub-line, small icon.

**Provide** `label`, `value`, `sub`, `subTone` (`success` for "N ready for pickup"), `icon`, `tone="key"` for the single most important card of the page, `negative` (Net Cash below 0).

- Replaces the mixed Tailwind colours (emerald, rose, blue, amber, sky) of the Monthly Summary and the dashboard quick buttons with this one style.

**Keep the app's structure.** This restyles the existing component; it does not add, remove or rename props, fields, buttons or behaviour.
