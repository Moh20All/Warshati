# Icon

A 24px line icon set drawn for Warshati: 1.75 stroke, round caps, `currentColor`. It can replace the icons the app uses today one for one (sidebar items, buttons, table actions).

**Provide** `name`, optional `size` (default 18) and `label` when the icon stands alone.

- Direction icons (`chev-end`, `undo`, `send`, `logout`, `collapse`) mirror in Arabic.
- A status icon always sits next to its word.

**Keep the app's structure.** This restyles the existing component; it does not add, remove or rename props, fields, buttons or behaviour.
