# Marks

Per direction (trace = chosen; waw and lobe kept for reference): `mark-*.svg` colour mark in `primary` #0F4F3C for light grounds; `mark-*-tile.svg` app tile (`primary` ground, `accent` #C6EB3F mark) for dark grounds, the sidebar and the web; `mark-*-16.svg` heavier drawing for 16–32px; `mark-*-black.svg` in #000000 for print. Never put the bare green mark on a dark ground — use the tile.
