# Logos

Lockups (mark + ورشتي over WARSHATI) for the three directions, colour and pure black, plus the two wordmarks alone. Text is outlined from IBM Plex Sans Arabic Bold and IBM Plex Sans SemiBold, so no font is needed. Colour versions: `primary` #0F4F3C mark and Latin line, `text` #14201B Arabic name — use them on `bg`, `surface` or white only. Black versions (`*-black.svg`, ink #000000) are for thermal receipts, A4 and stamps. `lockup-trace*` is the chosen direction; waw and lobe are kept for reference only.
